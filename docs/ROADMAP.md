# Roadmap
- v0.1: original foundation.
- v0.2: independent settings screen, native state hash and resource string patches, native feature adapters, Radium external staging/installer, real game class build preparation.
- v0.3: verify full runtime on generation-1 vanilla and Radium separately; resolve actual Java and graphics compatibility. Profile each patch with repeatable benchmark.
- v0.4: investigate additional safe CPU optimization and block state memory deduplication. Consider more native API ports with precise tests.
- Future: full modern JAR adaptation is not promised; substantial game differences require per-mod ports. Full renderer fork, full Lithium/FerriteCore backports not implemented.

- v0.3 alpha bridge milestone: portable JAR preflight/conversion and native feature routing implemented; runtime validation remains open.

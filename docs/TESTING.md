# Testing protocol
1. Build using GitHub Actions (or networked local Gradle); confirm verifier passes. No Minecraft files in the released JAR or ZIP.
2. Start clean generation-1 profile without other mods. Check latest.log, create world, open Right Shift menu, check buttons and Escape, reopen and verify saved settings. Test chat, inventory, resize, fullscreen, resource reload and pause screen. Test both on desktop and multiplayer practice environment, follow server rules.
3. Benchmark vanilla/clean Legacy Fabric against Rylune baseline and each opt-in patch separately using identical settings, world, path, Java heap, resolution and hardware. Record 3 runs with 60 seconds warm-up; compare average FPS, 1% lows, p99, used heap and visual parity. No guaranteed improvement.
4. Test resource pool after restart, state cache with block updates/chunk load, and zoom with GUI open/closed. Check no particle changes at default. Test background/hidden caps and restore focus.
5. Renderer: stage pinned Radium, inspect requirements and Java bytecode, verify exact mapping generation independently. Use separate disposable profile. Test Radium alone first, then with Rylune; test GL errors, Intel driver and chunk/sky/entity rendering. Never combine with other rendering replacements. Do not publish as compatible before tests pass.
6. If problems arise, disable optional settings, remove offending JAR, preserve latest.log and crash reports. Local self-tests are not runtime evidence.
